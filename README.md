Faculty Workload Management System

About

A Python-based project that manages faculty weekly workloads using Pandas and CSV files. It helps track working hours, identify overloaded faculty, assign new subjects, and find available faculty members.

Maximum Weekly Workload: 16 Hours

Technologies Used:

Python 3

Pandas

CSV

Features:

Displays faculty workload summaries.

Identifies overloaded faculty members.

Assigns new subjects within the 16-hour limit.

Finds faculty with sufficient free hours.

Validates user inputs and updates CSV data.

How to Run

Install Pandas:

pip install pandas

Run the program:

python main.py

Project Files

main.py – Main Python program.

workload.csv – Faculty workload dataset.

Testing

All four test cases provided in the assignment were successfully tested.

Conclusion

This project simplifies faculty workload management and helps prevent over-allocation of weekly working hours.
